# 回声诊所 / Echo Clinic — v0.9.5 原型（第一幕）

## v0.9.5：会动的背景和界面

- 窗外的城市是活的：星星在闪，雨一直在下，楼里有些窗灯会忽亮忽灭，诊所的霓虹十字在"呼吸"、偶尔接触不良地闪一下，薄雾慢慢飘过，一架飞机闪着灯穿过夜空，每隔一阵有流星划过。做决定的那一幕（血红的天）会打闪电。
- 视差：天空、远处的楼、近处的楼分三层，跟着鼠标轻轻错动，像隔着一扇玻璃看城市。
- 换幕时整片夜景淡入新的颜色。
- 界面动效：
  - 图标悬停时会微微弹起；
  - 窗口关闭时缩小淡出；
  - 当前窗口的标题栏每隔几秒扫过一道光；
  - 右键菜单和开始菜单展开时有动画；
  - 通知从右边滑进来；
  - 能说的话换了一批时，按钮会一个接一个弹出来；
  - 她的头像在轻轻"呼吸"，稳定度低的时候，名字下面的稳定度条会闪。
- 控制面板里打开"减弱动效"，以上全部停下。


## v0.9.4：更丰富的颜色

- 壁纸换成窗外的像素夜景：渐变夜空、星星、月亮、亮着彩色窗灯的楼群、诊所楼顶的霓虹十字、细雨。夜空颜色随剧情变化：接诊时是青色，查进程是紫红，录音是深蓝，转诊信是洋红，做决定时是血红，谈约定时天边开始发亮，结局是黎明。第二夜整体偏冷。控制面板和桌面右键菜单里仍可以换回纯色壁纸。
- 每个程序有自己的颜色：患者监护青色、任务管理器绿色、检查台橙色、邮件金色、记事本蓝色、回收站灰色、控制面板紫色、病历粉色、夜班外包橙金、休息室洋红。桌面图标、窗口标题栏、任务栏按钮都用这个颜色；她的对话窗口是紫色。
- 修复：导出的 exe 里中文只能在空格处换行（缺少断行数据），现在和编辑器里一样正常换行。
- 按钮都带一点自己用途的颜色；她的每句话左边有一道淡紫色的线；开始按钮有四色小旗；任务栏顶边和桌面挂件的标题跟着当前这一幕的霓虹色。


## v0.9.3：演出、按钮和主界面

- 关键剧情节点有了全屏演出，模仿 PV 的剪辑：桌面撕成条带并 RGB 错位、代码自己打出来、大字随节拍盖章、Win98 报错窗口一个接一个弹出、她的立绘切片入场，最后一条横幅打出这一节的标题。覆盖的节点：
  - 关掉 17 号、对上 42 号的日志、她撤回消息、找回原话（"不"字被拔出来）；
  - 附件改名成 echo.boot、寄信前检查、伪造的授权、第二夜"早了一秒"、约定里多念的半句；
  - 五个结局。
  点击或按空格可以跳过。
- 她每条消息下面的"摘录 / 存疑 / 引用"现在都能用：
  - 摘录：把这句抄进"我的笔记.txt"；
  - 存疑：给这句打问号。如果那是她在嘴硬的话（比如"没事"），她会回你一句；
  - 引用：把这句放进输入框，方便你拿它去问她。
- 邮件"收取"会收到院方的催办信（每一幕一封）；"新建文件夹"会提示这台机器是只读的；点窗口左上角的小图标会弹出窗口菜单；点聊天窗里她的头像会打开患者监护；在患者监护里点她的脸，她会有反应。
- 主界面：
  - 聊天气泡改成像素风的凸起/凹陷样式，交接单像一张纸，字号统一成 12 号；
  - 头像下面多了一条稳定度条；
  - 选项区只占它需要的高度，对话区更大了；
  - 桌面右上角多了一个"活动桌面"挂件：时钟、离 00:00 的倒计时，还有她的实时生命体征——她嘴上说没事，曲线照样会跳。


## v0.9.2：重写回声的台词

回声的性格重新定调为：**要强、目的明确、很能忍**（详见 `docs/v0.9-echo-voice.md`）。

- 她不再求人、不再"麻烦您"。她和你谈条件："给我十分钟，听我说完。"
- 她从第一句话起就知道自己要什么：带着记忆离开。关 17 号、在自述里加"不"字、把自己装进转诊信、复述约定时多念半句，都是同一个计划里的一步。被拆穿时她直接认。
- 她不说疼。问她疼不疼，她说"没事"。真正的疼只在疼痛曲线、日志和她的"思考"里。只有你说出那句"雨会停的"，她才会承认一次。
- 她的破绽改成：越疼、越在瞒事，句子越短，越爱说"没事"。
- 各幕开场不再替你说话（之前会出现她在回答一个你根本没问过的问题）。
- 交接单、话题回答、证据反应、回收站文件、两夜对照卡片、结局台词、AI 人设，都按新口吻重写。在线 AI 探针 71/71 通过（deepseek-flash）。


这一版把整个界面改成了 **MEDIC-OS 98**：一台像素风的旧 Windows 诊所电脑。
设计说明见 `docs/v0.9-desktop.md`。

## 怎么玩

- **左边是和她的对话窗**。下面的按钮是你能说的话，点哪句就说哪句：
  - 青色：推进剧情的回答；
  - 蓝色：这一幕能问她的问题（问了不花 T）。
  - 也可以在输入框里自己打字。
- **右边是桌面**。双击图标打开应用。剧情走到哪一步，桌面上就会多出哪些程序：
  - 患者监护：她的稳定度、上下文和记忆，开始接诊、置顶记忆都在这里；
  - 任务管理器（第一幕）：点进程看日志。日志条是卡片，可以拖到疼痛曲线的尖峰上对时间，也可以拖进聊天窗给她看；"结束进程"要等你说得清它在干什么才放行；
  - 检查台（第二幕起）：旧版的解谜台，暂时原样装在一个窗口里；
  - 邮件：院方工单、匿名收购、系统通知；
  - 病历、夜班外包、休息室（有人康复以后才会出现）。
- **签字**：需要签字时会弹出"医生签字"窗口，按住印章直到圆圈走满。
- **开始菜单**：存档、读档、设置、重开这一夜、回到标题。

## v0.9.1：更像一台真的电脑

- 图标：单击选中，双击打开，回车打开选中的图标；按住可以拖到别的格子（放到另一个图标上会互换位置）；鼠标停在图标上会显示说明。
- 桌面：拖动可以框选图标。右键桌面可以排列图标、刷新、换壁纸、打开属性；右键图标有"打开"和"属性"。
- 窗口：可以最小化、最大化（双击标题栏也行）、拖右下角改大小；右键标题栏或任务栏按钮有"还原 / 最小化 / 最大化 / 关闭"；Alt+F4 关闭当前窗口。
- 开始菜单："程序"和"文档"两个子菜单、控制面板、帮助、运行…、存档读档、关机…。
- 托盘：点 ♪ 调音量，点时钟看今晚是第几夜，点钱包看账本。
- 新程序：
  - 记事本：读交接单，"我的笔记.txt" 可以自己写，笔记会跟着存档走；
  - 回收站：上一班删掉的文件，可以查看、还原、清空（清空后就找不回来了）；其中有新的线索；
  - 控制面板：壁纸、动效、全屏、音量、静音、操作提示、AI 设置。
- 任务管理器：右键进程可以"查看日志 / 结束进程 / 属性"。
- 邮件：邮件列表加预览窗格，未读邮件在图标上显示数字。
- 开新游戏时会弹出"欢迎使用 MEDIC-OS 98"，讲清楚怎么操作（可以在窗口里或控制面板关掉）。
- "运行"框里可以输入程序名（taskmgr、notepad……）打开对应程序。

## 新的 T 来源

- **算力出租**：任务栏托盘的"算力出租"开关。开着时每 12 秒 +1T，每夜最多 10T；代价是她的上下文少 1.5K，会更早忘事。
- **异常报告**：每发现一条新情报或证据（候选词、思考、日志对上……），院方都按 +1T 结算。
- 夜班外包、卖记忆、院方工单仍然保留。
