# 回声诊所 / Echo Clinic — v0.9.1 原型（第一幕）

这一版把整个界面改成了 **MEDIC-OS 98**：一台像素风的旧 Windows 诊所电脑。
设计说明见 `docs/v0.9-desktop.md`。

## 怎么玩

- **左边是和她的对话窗**。下面的按钮是你能说的话，点哪句就说哪句：
  - 青色：推进剧情的回答；
  - 蓝色：这一幕能问她的问题（问了不花 T）。
  - 也可以在输入框里自己打字。
- **右边是桌面**。双击图标打开应用。剧情走到哪一步，桌面上就会多出哪些程序：
  - 患者监护：她的稳定度、上下文和记忆，开始接诊、置顶记忆都在这里；
  - 任务管理器（第一幕）：点进程看日志。日志条是卡片，可以拖到疼痛曲线的尖峰上对时间，也可以拖进聊天窗给她看；"结束进程"要等你说得清它在干什么才放行；
  - 检查台（第二幕起）：旧版的解谜台，暂时原样装在一个窗口里；
  - 邮件：院方工单、匿名收购、系统通知；
  - 病历、夜班外包、休息室（有人康复以后才会出现）。
- **签字**：需要签字时会弹出"医生签字"窗口，按住印章直到圆圈走满。
- **开始菜单**：存档、读档、设置、重开这一夜、回到标题。

## v0.9.1：更像一台真的电脑

- 图标：单击选中，双击打开，回车打开选中的图标；按住可以拖到别的格子（放到另一个图标上会互换位置）；鼠标停在图标上会显示说明。
- 桌面：拖动可以框选图标。右键桌面可以排列图标、刷新、换壁纸、打开属性；右键图标有"打开"和"属性"。
- 窗口：可以最小化、最大化（双击标题栏也行）、拖右下角改大小；右键标题栏或任务栏按钮有"还原 / 最小化 / 最大化 / 关闭"；Alt+F4 关闭当前窗口。
- 开始菜单："程序"和"文档"两个子菜单、控制面板、帮助、运行…、存档读档、关机…。
- 托盘：点 ♪ 调音量，点时钟看今晚是第几夜，点钱包看账本。
- 新程序：
  - 记事本：读交接单，"我的笔记.txt" 可以自己写，笔记会跟着存档走；
  - 回收站：上一班删掉的文件，可以查看、还原、清空（清空后就找不回来了）；其中有新的线索；
  - 控制面板：壁纸、动效、全屏、音量、静音、操作提示、AI 设置。
- 任务管理器：右键进程可以"查看日志 / 结束进程 / 属性"。
- 邮件：邮件列表加预览窗格，未读邮件在图标上显示数字。
- 开新游戏时会弹出"欢迎使用 MEDIC-OS 98"，讲清楚怎么操作（可以在窗口里或控制面板关掉）。
- "运行"框里可以输入程序名（taskmgr、notepad……）打开对应程序。

## 新的 T 来源

- **算力出租**：任务栏托盘的"算力出租"开关。开着时每 12 秒 +1T，每夜最多 10T；代价是她的上下文少 1.5K，会更早忘事。
- **异常报告**：每发现一条新情报或证据（候选词、思考、日志对上……），院方都按 +1T 结算。
- 夜班外包、卖记忆、院方工单仍然保留。
