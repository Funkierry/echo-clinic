# ECHO CLINIC / 夜班诊所 v0.3

Windows 64 位可玩原型。Godot 4.7.2，纯 2D，800 × 480 逻辑画布，整数倍最近邻放大。

双击 `EchoClinic.exe` 即可运行。此版本独立于 v0.1 / v0.2；旧版程序和存档保留。

## 这一版怎么玩

左侧是持续的问诊聊天：回复逐字出现，建议回复和输入框始终在底部。无需反复按“继续”才能使用仪器。右侧随着调查变成不同的修复界面：

1. **进程追踪**：比较 CPU、写入记录、回滚记录与外联状态，找出持续覆盖患者自述的进程。暂挂错误对象会撤回，不扣额度。
2. **内存纠错**：两页各有一个翻转的比特。用行列偶校验恢复原页；可以翻转与还原，不会损坏原始记忆。
3. **数据包重组**：根据 ID / PREV 指纹连接四个碎片，读出被“诊断包”这个名字掩盖的载荷。点击已接入的槽位可以撤回。
4. **权限手术**：在副本中调整人格、维护进程和中继的权限，观察写入、外联和自动回滚。通过试运行后才可提交治疗。

案件有三条结局。自定义治疗在第一轮即可选择，不强制玩家先输一次。重开保留医生病历、已见结局与检查结果；完成过检查后，可以直接回到处方审计。回声的接诊快照会复原，但她与院方的可信度，需要你自己判断。

## 操作和引导

- 左侧建议回复 / 输入框：发起检查或询问当前话题。输入“提示”“卡住”“下一步”可打开线索便签。
- 右侧角标呼吸：标记当前可调查的区域。按钮悬停会轻微抬起、倾斜。
- 底栏“当前”：只说明调查目标，不显示谜底。
- “?” / “线索”：观察方向 → 推理线索 → 直接解法，逐级主动展开，免费。
- 空格：补全当前聊天，或跳过演出；输入框内空格仍用于输入。
- Esc：关闭便签 / 跳过演出 / 退出全屏。F11：全屏切换。
- 声音 / 动效：静音，或减少位移、粒子与悬停动画。
- 上滚聊天或拖动滚动条：暂停跟随；“回到最新消息”恢复跟随。

补充问诊每个新话题消耗 2T，重复与未理解的问题不扣费。检查奖励额度，治疗所需的 20T 不会被可选对话花掉。主线线索不需要购买。

## 演出与美术

以深蓝、钴蓝为底，用薄荷青、琥珀、珊瑚粉和淡紫区分检查语义。中文采用 Fusion Pixel 12px 点阵字；角色重新生成成粗像素二次元形象，并在游戏内按 56 × 76 的采样格渲染。

连续聊天、碎片回流、窗口横向侵入、抹除、出走与重新聚合，分别对应病例的节点。权限试运行会播放八拍副本检测。所有系统操作仅是游戏内模拟，不会操作电脑上的真实进程、权限或网络。

参考了作者公开的 [PV 制作说明与源码](https://github.com/MisakaZentai/world-execute-me-dsh-pv) 的左右舞台调度，以及 [dsh-thought-window](https://github.com/Funkierry/dsh-thought-window) 的连续像素转场思路。研究材料为作者预览、制作说明和源码，并非完整视频观看。没有打包参考视频的歌曲、立绘或舞蹈资源。

角色资产使用内置 image_gen 生成；完整提示词、方式和资产路径在 `art-direction.json`（源码中为 `tools/art-direction-v03.json`）。项目资产位于 `project/assets/v3/echo-chunky.png`。字体、Godot 及原项目仍包含的字体资源许可在 `licenses/`。

## 当前边界

聊天仍是本地剧情脚本与上下文话题匹配，不接真实大模型，不联网。输入框可以询问提示与当前话题，但不支持任意自然语言推理。此版本用于体验交互、谜题与演出；不是完整游戏。

存档：`%APPDATA%\Godot\app_userdata\ECHO CLINIC · 回声诊所\case-v3.json`。有效操作后自动保存；同时保存聊天记录和未播放的消息。加载权限手术存档后，需要重新试运行一次。偏好保存在同目录 `preferences.cfg`。

## 开发与验证

用 Godot 打开 `project/project.godot`。v0.3 入口为 `project/scripts/v3/main.gd`；模型 `case.gd`、聊天剧情 `story.gd`、动态修复界面 `workbench.gd`、演出 `cinema.gd` 相互分离。旧脚本保留供版本比较，主场景不会加载它们。

自动检查覆盖：阶段守卫、重复奖励、错误操作回退、两页所有单比特候选、24 种数据链排列、512 组权限组合、预算保护、三条结局与重开复用、JSON 恢复、原子存档替换、聊天记录以及实际 Godot 鼠标输入驱动的完整流程。`test-report.json` 是本次导出的实际结果，`preview.png` 是引擎渲染截图。

运行测试：`Godot.exe --path project -- --self-test --capture-dir=<绝对目录>`。

源码包需要自行安装对应 Godot 和 Windows 导出模板；导出预设不包含开发机器的模板路径。
