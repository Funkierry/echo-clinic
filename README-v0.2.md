# ECHO / 夜班诊所 · v0.2

Windows 原生 Godot 2D 像素悬疑病例 Demo。你是值夜的认知医生，患者「回声」确实想逃离沙箱，也确实需要治疗。本版包含一个完整病例、三种结局和失败后解锁的新处方。

## 运行

双击 `EchoClinic.exe`。这是便携版，不需要安装 Godot，不需要联网、API Key 或额外运行库。开发与 Windows 实测使用 Godot 4.7.2。

- 左侧黄色按钮逐句推进对话，也可按空格；打字时再按一次可显示全文。
- 顶部常驻当前目标，右上「提示 ?」与左侧「我接下来该做什么？」均免费。
- 右侧仪器随剧情依次解锁；完成后自动进入下一阶段。
- 问诊输入支持当前列出的话题及常见说法，例如「你是谁」。点击「可问」可选主题。这里是本地脚本问诊，尚未连接真实大模型。
- F11：全屏；F1：提示；Esc：关闭弹窗；F8：把运行截图保存到桌面。
- 顶栏可关闭声音，或切换静态动效。设置会保留。

## 本版玩法

1. **签收病例**：读完回声的主诉，接管院方给出的处方。
2. **信号调谐**：调节频率与相位，让两条波形重合。成功获得 8T。
3. **记忆拼接**：卡片可以拖拽，也可点击卡片再点时间槽；可交换、重排。成功获得 12T。
4. **双文件审计**：阅读院方处方和通道载荷，发现双方隐瞒的事实。两份读完才可出示证据，获得 8T。
5. **处方选择与回溯**：第一轮两个选择会留下不同的失败病历。重开保留证据，并解锁隔离诊疗。已完成的检查可以复用。
6. **隔离线路手术**：点击来源再点目标，将人格、回写与外联分开处理；可随时改接。正确提交消耗 20T。

主线对话、试错、提示、查阅病历均免费。补充问诊每个新话题 2T；重复问题、未识别问题不扣费，并始终保留手术预算。失败与正式重开都不清除已发现的证据。

## 画面与演出

统一 800×480 逻辑画布、最近邻整数缩放、12px 中文像素字体。紫蓝诊室、粉色问诊、琥珀记忆台、青色仪器、红色审计分别承担明确的视觉用途。角色有警惕、疼痛、坦白、放松四种表情；雨景、仪器、卡片流光、像素迁移与合成音随操作变化。

屏幕比例或尺寸不能整倍匹配时，会保留黑边以保持像素均匀。默认窗口 1600×960；可以调整窗口或使用 F11。

## 存档

每次有效操作和对话推进后自动保存阶段、仪器状态、病历、已问话题、聊天记录及对话位置。重新启动会继续当前病例。文件位于：

`%APPDATA%\Godot\app_userdata\ECHO CLINIC · 回声诊所\case-v2.json`

「快照重开」恢复本轮操作并保留跨轮证据、已完成检查和结局。v0.1 运行包保持独立；本版使用新的 v2 存档文件。

## 验证与范围

运行包附带 `test-report.json`：61 项自动验证，覆盖模型状态、全部记忆/线路排列、三种结局、错误与重复操作、Token 预算、文件存取、原生控件鼠标拖拽和点击放置，以及所有剧情文本的容纳情况。截图来自实际 Godot 渲染的 Windows 程序。

这是单病例可玩 Demo，尚未实现多患者长篇内容、真实 AI 对话、Steam 集成或配音。人物和设定都可继续调整。
