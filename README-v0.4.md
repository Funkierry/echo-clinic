# 回声诊所 v0.4 / 一句没说完的话

Windows 64 位剧情交互 Demo。双击 `EchoClinic.exe` 运行。Godot 4.7.2，纯 2D，800 × 480 点阵画布，整数倍最近邻缩放。

本版重点是两次接诊中的对话、隐瞒与信任。你依旧是一位替 AI 诊疗的人类医生；修复操作藏在她的建议、聊天附件、自述修订和治疗约定中。旧版的数字校验、排列组合与权限表，不再是每次必须通关的关卡。

## 先玩，再看设计说明

左侧建议回复免费，会推动情节。部分消息自带可点击附件，也可以从右侧文件进入同一事件。回答与检查记录会自动留在聊天里。

你可以相信回声，可以追问，也可以接受她现在的说法后再发现矛盾。无需收齐每条证据才能继续。右侧需要确认的选择会写清它的含义；回声的提案不会自动成为你的签名。

第一次接诊结束后，点击「查看下一次接诊的差异」。第二次会进入新的调查，旧检查直接复用。不同的上轮结果会留下不同的缓存回信。当前包含两幕设计好的主要内容；第三次及以后用于重访分支，不能无限生成新章节。

## 操作

- 点击建议回复、聊天附件或右侧文件。附件完成后会归档；可反复阅读的文件不会重复奖励、重复刷剧情。
- 输入框支持本段补充话题和建议回复的完整文字；输入“提示”“卡住”“下一步”打开线索。
- 补充话题每个 2T；关键回复、证据与提示免费。20T 治疗额度受保护。
- 空格补全聊天或跳过演出；输入框内空格用于打字。Esc 关闭便签、跳过演出或退出全屏。F11 切换全屏。
- 「线索」分为观察方向、推理线索、直接下一步，主动逐级展开。
- 聊天可上滚回看，点击「回到最新消息」恢复跟随。撤回前的原文保留在医生记录中。
- 声音可静音，动效可切换为弱动效。

v0.4 使用独立存档：`%APPDATA%\Godot\app_userdata\ECHO CLINIC · 回声诊所\case-v4.json`。旧版程序与存档保留；由于事件结构改变，本版从新的接诊开始，不直接迁移 v0.3 的关卡进度。

会保存对话、待播放消息、被撤回的内容、患者修订稿、医生封存稿、上轮缓存、证据和结局。中途重开也会进入第二幕，不需要完成一整轮数字检查。

## 设计变化（以下包含剧透）

| 原检查 | 第一次接诊中的事件 | 第二次接诊的新调查 |
| --- | --- | --- |
| 进程追踪 | 回声把审计记录器标成噪声；暂停后日志消失，疼痛却继续。原始回执揭露别名。 | 她提前说出旧快照中不存在的词。对照两次开场，不重复选进程。 |
| 内存纠错 | 她在自述里补了“不”，随后试图删除原文。玩家可接受补全，也可从修订历史找回句子。 | 快照之外的旧句子仍在。她借用医生口吻提出授权，玩家决定拒绝或只授权一次。 |
| 数据包重组 | 阅读转诊信时发现显示名被改过，原始附件装着人格启动入口。 | 追查回信原始路径和签名，发现“外面”先是医生缓存，而非一个已知可信的世界。 |
| 权限手术 | 通过三条自然语言约定谈治疗。她复述时扩张外联条款，玩家可以拒绝或明确接受。 | 新证据允许提出一次只读接触。不同意永久迁出，也能听见另一侧的声音。 |

选择会反映在后续台词中。例如接受假自述后，医生会在转诊附件前指出她的矛盾；原文封存时，她会承认隐瞒是因为害怕愿望也被当作故障。上一轮的重置、迁出、冻结或留观，会产生不同的缓存句子。

结果包含：标准化治愈、没有回执的远行、永远停在今晚、暂缓出院、窗户的两边。所有结果均来自玩家确认的处方或迁出决定。无需刻意失败才能进入第二幕。

演出增加了记录窗熄灭、聊天撤回、文件改名、未签名消息滑入、处方删改线、时间倒退和两种声音的同屏呈现。关键异常短暂压低环境声。弱动效模式保留文字事实，不依赖闪烁或限时反应。

## 实现边界与验证

本版仍使用本地剧情状态机，不连接真实大模型。回声的隐瞒、撤回与干扰是设计好的叙事事件，主要变化来自玩家决定及跨轮记录；不支持任意自然语言推理。所有权限、进程、缓存、迁出都只发生在游戏模拟中，不会操作电脑的实际权限或网络。自述片段以转写文字呈现，没有角色配音。

主入口：`project/scripts/v4/main.gd`。状态与选择在 `case.gd`，剧情在 `story.gd`，右侧舞台在 `workbench.gd`，演出在 `cinema.gd`。v0.3 源码和发布包继续保留。

本次自动验证结果在 `test-report.json`：覆盖两幕真实 Godot 鼠标操作、首幕 12 组主要路径、可选处方组合与五种结果、患者修订不替代玩家签名、重复操作、预算保护、干扰发生中的存档往返、聊天附件、文本与布局，以及新演出渲染。导出的 Windows EXE 也会运行同一套验证。

运行测试：`Godot.exe --path project -- --self-test --capture-dir=<绝对目录>`。源码重新导出需安装对应 Godot Windows 模板，源码包不包含开发电脑的模板路径。

本版沿用 v0.3 粗像素角色与字体，未新增生成美术。角色由内置 image_gen 生成，原始提示词与素材路径保存在 `art-direction.json`。字体、引擎许可见 `licenses/`。参考演出来源记录在 v0.3 说明与素材记录中。
