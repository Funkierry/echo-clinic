# 回声诊所 v0.8 · 试玩版

Windows x86-64 / Godot 4.7.2。双击 `release/EchoClinic-Windows-v0.8.3/EchoClinic.exe` 即可运行，不需要安装任何东西。

> 23:47，闭院前的最后一位患者是一个 AI。院方付钱让你清空她。她说：先听我说完。

当前试玩包是 **v0.8.3**：`release/EchoClinic-Windows-v0.8.3/EchoClinic.exe`。

## v0.8.3：先看剧情，再动手

- **剧情优先**：她说话时，右侧检查台会锁住、调暗，显示“先听她说完”。她说完以后，检查台才会亮起来，卡牌一张张发到桌上。节奏变成“左边看剧情 → 右边动手”。
- **对话变慢**：打字速度降到每秒 22 字左右，句子之间按长短停顿，等待时显示“回声正在输入”。按空格可以跳过。
- **检查台更图形化**：
  - 所有卡牌都带图标。
  - 开场：工单做成票据，加了心电线；她身上有一个接口，从接诊线牵出一根电缆。
  - 第一幕：进程变成节点连线图，改写会沿着线流向她。
  - 第二幕：编辑历史变成一叠版本卡，把上面那张拖开就能看到下面的原话。
  - 第三幕：文件变成图标方块。
- **界面按需出现**：底部的工单、病历、外包、重开按钮在用得上时才出现，第一次出现时会弹一下。
- **打磨**：
  - 发呆 8 秒，能拖的卡会抖一下。只提示“这个能动”，不提示该拖到哪。
  - 拖动中途有新消息，检查台不再重建打断你。
  - 弹窗缩放淡入；教学气泡放到目标侧面，不再挡住底部按钮。

## v0.8.2 新增：新手教学与存档

- **标题菜单**：启动后先进标题界面，可以选择继续、新的夜班、读取存档、设置或退出。新的夜班会先播一段开机动画，点击可跳过。
- **教学提示**：每种操作第一次出现时，上一班的便签会指给你看，只讲“怎么操作”，不讲答案：
  - 拖卡（带一个演示拖动的虚影）、按住签字、直接打字聊天、点开日志；
  - 闪烁的候选词、「已思考」、上下文快满时置顶；
  - 没钱接外包、收购记忆、院方工单。

  做过一次就不再出现。气泡上可以「关闭教学」，在设置里也能重新显示全部教学。
- **存档**：
  - 1 个自动存档，加 3 个手动存档位，每个存档位显示缩略图、第几夜、当前一幕、钱包和保存时间；
  - 游戏中按 `Esc` 或点「菜单」暂停，可以保存、读取、改设置、回到标题；
  - 写存档时先写临时文件，并保留上一份作为 `.bak` 备份，文件损坏时自动从备份恢复；
  - v0.8 / v0.8.1 的旧存档会自动变成自动存档。

## v0.8.1 改了什么（根据第一次试玩反馈）

- **更难、更靠自己摸索**：去掉了聊天下面的推荐回复、聊天里的线索快捷按钮、底部的「提示」按钮和“当前：……”目标文字。真卡住时，在聊天里输入「卡住」或「提示」，还能看到前任医生的提示便签（第三层要 1T）。
- **检查台全部改成动手操作**：
  - 把接诊线拖到她身上开始接诊；
  - 把日志条拖到疼痛曲线的尖峰上对时间；
  - 把 SIGSTOP 卡拖到你认为该停的进程上；
  - 把原话或补全稿拖进病历；
  - 把 `-a` `-l` `-t` 拖进命令行，把文件拖进 `cat` 阅读器；
  - 把条款卡拖进槽位，把印章盖在你选的那一份上；
  - 所有签字改为**按住不放**。

  界面不会告诉你哪个是对的，放错了卡会弹回去。
- **小丑牌式手感**：
  - 卡牌用弹簧物理，悬停时浮起并朝鼠标倾斜，有光泽扫过；拖动时随速度摆动，放下时弹性吸附。
  - 按钮按下压扁、松开回弹。
  - 钱包数字滚动并飘出“+6T”；关键时刻屏幕震动、短暂停顿、字符粒子迸发；剧情转折的大字逐字砸下。
  - 外包小游戏的连击音一路升高。
- **全新音乐与音效**（全部脚本合成）：80 BPM 的 D 小调环境乐分成四轨，按剧情紧张度叠加；20 多种手感音效。

## 这一版变了什么

- **界面**：改成 PV 式的终端风格。左边是聊天窗，右边是“她的世界”，底部是她当前这句话的逐词字幕。字体清晰，带辉光和扫描线。回声在舞台上由字符拼成，会随情绪变化。
- **剧情**：按新剧本重写，每一幕只问一个问题，台词改成了大白话。新增院方工单（会涨价）、前任医生的交接单，以及第二夜的揭晓。
- **解谜**：进程表对日志时间、拖动录音和编辑历史、在小终端里用 `-a` / `-l` / `-t` 翻文件，还有约定复述比对。
- **藏在对话里的情报**：
  - **候选词**：她的话里偶尔有一个词会轻轻闪，点开能看到她差点说出口的另一个词。
  - **已思考 ›**：她每条重要消息下面都有一条折叠的思考，花 T 才能展开，读得越多越贵。
  - **知识钥匙**：发现的某些话，可以直接在聊天里对她说出来。
- **经济**：
  - 开局只有 12T。
  - 聊天不扣 T，但会占用她的**上下文**。上下文满了，她会真的忘掉最早的事，可以花 T 置顶保护。
  - 收入来源有三个：「缓存命中」外包、院方赏金、把她的记忆卖给匿名收件人（卖掉的她就忘了）。
  - 每夜结束有一张结算单。
- **签字**：只有不可逆的操作（执行治疗、执行工单、送走她、中途重开）需要在检查台上签字。
- **AI 对话**：回声和灯芯的人设重写，71 条极端问题实测全部守住；玩家表达轻生念头时，由游戏直接给出求助信息。

## 怎么玩（不剧透）

1. 读一下聊天窗里的交接单。想接诊，就把检查台上的「接诊线」拖到她身上（−4T），或者在聊天里告诉她你在听。
2. 右边的检查台是你的工具：点、拖、翻文件。她说的话和设备留下的记录，常常对不上。
3. 真卡住了，在聊天里输入「卡住」：前两层提示免费，第三层直接给做法，要 1T。
4. 钱不够时点 **外包**：45 秒的配对小游戏，最多赚 12T，一夜最多 3 单。
5. 聊天窗底部的 **上下文** 条可以点开，看她还记得什么、下一个会忘掉什么。

快捷键：
- `F11`：全屏。
- `Esc`：关闭弹窗。
- 空格：跳过演出或补全正在打的字。
- 外包时：`1`–`4` 选择回答，空格抓取可疑消息。

## 接入 DeepSeek（可选）

不接 AI 也能玩完整个流程，回声会用本地写好的短回应。想和她自由聊天：

1. 在游戏 AI 设置中填写自己的 Key，也可以设置用户环境变量 `DEEPSEEK_API_KEY`。
2. 点聊天窗右上角的 **AI 离线** → **接入会话**；通过环境变量提供时会自动填入密钥。

游戏里的 T 和 DeepSeek 的真实费用无关，后者按你的 DeepSeek 账户计费。

## 存档

存档在 `%APPDATA%\Godot\app_userdata\ECHO CLINIC · 回声诊所\saves\`：`slot_auto.json` 是自动存档，`slot_1`–`slot_3` 是手动存档，每个都有 `.bak` 备份和一张缩略图。想从头开始，在标题界面选「新的夜班」即可，手动存档不受影响。
