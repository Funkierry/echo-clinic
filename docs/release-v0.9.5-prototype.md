# 回声诊所 v0.9.5 · 动态夜景与剧情演出

汇入 v0.9.2 至 v0.9.5 的更新：

- **回声的新口吻**：重写两夜台词与 AI 人设，突出要强、隐忍和带着记忆离开的目的。
- **关键剧情演出**：线索揭晓与结局加入全屏剪辑、代码打字、报错弹窗、立绘切片和标题盖章，可点击或按空格跳过。
- **更多聊天互动**：摘录到笔记、标记存疑、引用追问；头像、患者监护和邮件也有新的回应。
- **动态像素城市**：夜景随剧情变色，雨、窗灯、霓虹、薄雾、飞机、流星与闪电持续变化，前后景随鼠标轻微移动。
- **界面打磨**：各应用独立配色，新增图标、窗口、菜单、通知和头像动效；支持减弱动效。修复 Windows 导出后的中文换行。

## 下载

下载 `EchoClinic-Windows-v0.9.5-prototype.zip`，解压后运行 `EchoClinic.exe`。Windows x86-64，无需安装 Godot。

源码包为 `EchoClinic-Godot-source-v0.9.5-prototype.zip`，使用 Godot 4.7.2 打开 `project/project.godot`。压缩包 SHA-256 见附件校验文件。

无 API Key 也能完成剧情；自由 AI 聊天可在游戏内填写 DeepSeek Key，或通过 `DEEPSEEK_API_KEY` 环境变量提供。游戏 T 与真实 API 费用分别计算。
