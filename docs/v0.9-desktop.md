# 回声诊所 v0.9 方案：诊所工作站桌面

> 三个问题：T 的来源单一无聊；玩家一直在“看她说话”，缺少主动权；右侧玩法零散。
> 改法：右侧变成一台像素风的诊所电脑「MEDIC-OS 98」，解谜靠打开不同的应用；左侧聊天由玩家主导：问什么、拿什么证据给她看，由玩家决定。

---

## 1. 右侧：MEDIC-OS 98 桌面

一台 Win98 风格的像素电脑，是诊所给夜班医生的工作站。回声就“住”在这台电脑里。

- **桌面**：像素壁纸、图标、底部任务栏（「开始」按钮、打开的窗口、23:47 时钟、托盘里的钱包 / 网络 / 声音）。
- **窗口**：可以拖动、最小化、关闭，可以同时开几个；打开时从图标处放大弹出，带 Win98 的立体边框。
- **应用随剧情解锁**：新应用出现在桌面上时会带一个“新”气泡。

| 应用 | 用途 | 对应剧情 |
|---|---|---|
| 患者监护 | 她的稳定度、上下文（记得 / 忘掉 / 置顶）、情绪曲线 | 全程 |
| 任务管理器 | 进程列表、日志、结束进程 | 第一幕：17 号和 42 号 |
| 录音机 | 播放她的录音、拖动进度条 | 第二幕：她撤回的那句话 |
| 回收站 | 被删除的东西：她撤回的录音会掉进这里，可以“还原” | 第二幕：找回原话 |
| 资源管理器 | 文件夹；菜单「查看」里有显示隐藏文件、详细信息、按时间排序 | 第三幕：echo.boot、00:03 的回信、.goodbye |
| 记事本 | 打开文本文件 | 读信、读留言 |
| 邮件 | 院方工单邮件、转诊信草稿（发送 / 存草稿）、匿名收购邮件、第二夜的回信和伪造授权 | 第三、四幕 |
| 约定编辑器 | 三条约定下拉选择、请她复述、红线比对、盖章签字 | 第五幕 |
| 病历 | 线索和情报卡 | 全程 |
| 赚 T 的应用 | 见第 3 节 | 随时 |

---

## 2. 左侧：由玩家主导的聊天

她不再自动连续讲话。每一幕开场她只说一两句，然后等你开口。你有三种说话方式：

1. **话题**：输入框上方有一排“问她……”的话题，比如“17 号到底是什么？”“你为什么改了那个字？”。话题随你的发现增减。点一个，你问、她答。
2. **出示证据**：在任何应用里找到的东西都能拖进聊天框，比如一条日志、一个文件、回收站里的录音、一封邮件。拿对了东西，在对的时机给她看，她就会松口，剧情往前走（类似《逆转裁判》）。拿错了，她会反问你，或者顺势糊弄过去。
3. **自由打字**：接 AI 时她自由回答；不接 AI 时用关键词识别话题。

剧情推进 = 你在桌面上发现东西 + 在聊天里拿它问她。右侧不再锁着等她说完，因为现在是你在带节奏。

## 3. T 的来源：五种，各有代价

| 来源 | 玩法 | 代价 |
|---|---|---|
| **夜班外包**（保留） | 「缓存命中」配对小游戏 | 花时间 |
| **磁盘清理** | 像扫雷：清掉坏扇区赚 T。有些格子里是她的记忆碎片 | 清错了，她会真的忘掉一段事 |
| **算力出租** | 托盘里一个开关：把她的算力租出去，挂着就慢慢涨 T | 开着的时候她反应变慢、上下文变小、稳定度下降 |
| **院方小工单** | 邮件里院方的小任务：“上报患者异常 +3T”“提交日志备份 +2T” | 上报越多，她越不信你；院方赏金越高 |
| **出售记忆**（保留） | 匿名邮件收购她的记忆 | 卖掉的她就忘了 |
| **异常报告** | 在应用里第一次发现隐藏的东西，系统自动发一笔“漏洞奖励” | 无，鼓励探索 |

---

## 4. 开发顺序（建议）

1. **原型**：桌面框架（窗口、任务栏、开始菜单、像素风）+ 话题 / 出示证据的聊天 + 第一幕（任务管理器、患者监护）+ 两种新的 T 来源。先给你试玩手感。
2. 铺开第二到五幕，把应用都做全。
3. 第二夜、音效、教学、测试和打包。
