# 回声诊所 v0.9.1 · MEDIC-OS 98 桌面原型

这次同步包含 v0.8 系列的剧情、记忆与经济系统，以及 v0.9.1 的像素桌面体验。

- 左侧聊天可以选择话题、自由输入或拖入证据；右侧通过诊所电脑调查回声的病情。
- 第一幕改为任务管理器和患者监护：检查进程日志、对照疼痛曲线，再追问她。
- 支持图标拖动、框选、右键菜单、窗口缩放与最大化、开始菜单、控制面板和运行框。
- 新增可保存笔记的记事本、藏有线索的回收站、带未读提示的邮件列表。
- 增加算力出租与异常报告收入；保留上下文、记忆置顶、外包、院方工单和出售记忆。
- 包含新剧本、候选词和折叠思考、拖卡与签字演出、合成音乐音效、教学、自动与手动存档。

## 下载和运行

下载 `EchoClinic-Windows-v0.9.1-prototype.zip`，解压后运行 `EchoClinic.exe`。Windows x86-64，无需安装 Godot。

没有 API Key 也能完成剧情。自由 AI 聊天可在游戏设置填写 DeepSeek Key，或者通过 `DEEPSEEK_API_KEY` 环境变量提供。游戏 T 与实际 API 费用分别计算。

源码包为 `EchoClinic-Godot-source-v0.9.1-prototype.zip`，使用 Godot 4.7.2 打开 `project/project.godot`。两个压缩包的 SHA-256 见附件校验文件。

## 验证与范围

- 源码和 Windows EXE 分别通过 344 项本地检查，涵盖剧情流程、确认操作、桌面交互、经济、存档和模拟 API。
- 本次使用本地 HTTP 模拟接口，未重跑真实 DeepSeek 测试。v0.8 的人设测试属于历史验证记录。
- 当前为第一幕桌面玩法原型；第二幕以后与第二夜仍使用窗口内的旧版检查台，专用桌面应用尚未全部完成。
- 仓库保留 v0.7.0 标签与 Release，方便回退和比较。
